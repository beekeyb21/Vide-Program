# 01 Supervisor Program

## Overview

Supervisor là script Python chạy cuối mỗi session Claude Code. Giải quyết 2 vấn đề:
1. **Context tràn** → sinh `context_snapshot.md` (~500 tokens)
2. **Chi phí Claude.ai** → Meta-Planner đọc snapshot thay vì 8-10 Notion pages

---

## Spec

### Input
- `--project`: Path tới project folder
- `--mode`: `snapshot` (default) | `audit`
- `--notion`: Optional Notion Handoff URL

### Output

#### Snapshot mode
- `context_snapshot.md` trong project — tóm tắt session gần nhất
- Notion Handoff updated (nếu `--notion` provided)
- Console: session summary + token budget

#### Audit mode
- Full audit report
- All files reviewed
- Gap analysis

## Context Snapshot Format

```markdown
## Session Snapshot — [DATE]

**Project:** [NAME]
**Phase:** [X]
**Session:** [N]

### Accomplished
- [Bullet 1]
- [Bullet 2]

### Blocked
- [Item] — waiting for [decision needed]

### Next
- [Immediate next action]

### Metrics
- Tokens used: ~[N]
- Files changed: [N]
- Tests: [N] pass / [N] fail

---
*Auto-generated by Supervisor*
```

## Token Budget Monitor

| Budget | Threshold | Action |
|--------|-----------|--------|
| 80% | Warning | Print warning |
| 95% | Critical | Auto-compact after session |
| 100% | Done | Stop session immediately |

---

## Notion Handoff Update

When `--notion` provided:
1. Fetch current Handoff page content
2. Append new session block
3. Update Current Status table
4. Push updated content back

---

## Exit Codes

| Code | Meaning |
|------|---------|
| 0 | Success |
| 1 | Error (file not found, API error) |
| 2 | Token budget exceeded |
